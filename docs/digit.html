Webpage Reflictive Essay

Overall for developing a website I wholeheartedly prefer using HTML to create my own markup for the page. It gives me more control and a better understanding of what can be done and how to do it. I think the most challenging part of HTML is finding a function that does what you want it to do without breaking other functions, especially with CSS styling. I find using a webpage builder to be monotonous and difficult to navigate. Many simple functions are hidden behind 3 or more pages. It is also difficult to troubleshoot especially if you don't already have HTML experience. Overall I think HTML is the better way to create a proper website to store whatever information you may desire. I could only ever see myself using a webpage builder to create basic sites such as an image gallery or a way to share information in a semi-professional manner.
